### 主要功能：
1. 【整站全量备份与无缝迁移（ZIP 打包）】：已修复容器及小窗口下显示与导出不全问题；普通用户权限隔离（仅管理员可见整站备份，普通用户仅支持导出个人卡片数据）。
2. 【云存储与多端漫游图床】：支持 GitHub 仓库 与 Cloudflare R2 (S3 通用协议) 双引擎，支持一键全部拉取到本地、单张同步、多选批量删除及清空图床。
3. 【本地 + 云端双写机制】：默认保持关闭，用户授权后自动将新上传的图标与壁纸双写备份至云端。
4. 【仓库属性智能感知】：自动探测目标仓库为私有 (Private) 还是公开 (Public)，提供安全状态指引。
5. 【AES-256 强加密备份保障】：上传云端全站备份前强制要求用户手动输入加密密码，采用行业级 AES-256-GCM 算法加密，防范公开外链泄露风险。
6. 【系统弹窗自由拖拽与拉伸缩放】：系统应用窗口支持鼠标按住标题栏平滑拖动移动、双击居中复位，右下角调节手柄支持左上固定向右下自由拉伸缩放宽度与高度。
7. 【图库管理与普通用户防越权】：原上传文件管理升级为“图库管理”，支持【壁纸图库】与【应用图标】双分类互相移动与重命名；支持多选批量删除；后端 SQL 严格限定用户 ID，普通用户只能删除自己的图片，绝对无权删除他人图片。
8. 【普通用户申请与管理员审批流】：普通用户上传后可申请同步至云端图床；管理员专属待审列表支持一键全部批准并推送到云端。
9. 【内置管理员图库选择器】：卡片编辑选择在线图标改为内置弹窗拾取管理员图库/公共图标，点击自动填充，无需离开页面。
10. 【默认初始账密】：默认管理账号为 admin，默认密码为 12345678。
11. 【多架构支持】：支持 linux/amd64 (x86_64) 与 linux/arm64 (ARM64 如各类主流 NAS) 自动化云端构建。

### 🚀 一键部署 (Docker Compose)

在您的 NAS 或服务器创建 `docker-compose.yml`：

```yaml
services:
  sun-panel:
    image: ghcr.io/mysecret2022/my-sun-panel:latest
    container_name: firefly-panel
    restart: always
    ports:
      - "3002:3002"
    volumes:
      - ./conf:/app/conf
      - ./database:/app/database
      - ./uploads:/app/uploads
      - ./files:/app/files
```

执行命令一键拉起：
```bash
docker compose up -d
```
打开浏览器访问：`http://<您的IP>:3002`（初始管理员账号：`admin`，默认密码：`12345678`）
